# Artigo acadêmico — padrão SBC

O artigo será entregue em 23/11/2026. Os arquivos desta pasta constituem a estrutura inicial, ainda incompleta.

## Utilização no Overleaf

1. Abra o [SBC Conferences Template (versão 2017)](https://www.overleaf.com/latex/templates/sbc-conferences-template/blbxwjwzdngr) e crie uma cópia.
2. Preserve os arquivos oficiais de formatação do modelo, especialmente `sbc-template.sty` e `sbc.bst`.
3. Substitua o conteúdo do documento principal pelo código de `main.tex` e importe `referencias.bib`.
4. Preencha os nomes reais dos integrantes e a afiliação.
5. Complete fundamentação e metodologia, confira as citações, compile e revise o PDF.
6. Registre os arquivos-fonte e o PDF definitivo neste repositório.

O Word da professora orienta os conteúdos e a avaliação. O formato SBC foi escolhido pelo grupo.

**Atenção:** o arquivo inicial contém seções pendentes. A entrega deve ser revisada antes do envio à professora.
